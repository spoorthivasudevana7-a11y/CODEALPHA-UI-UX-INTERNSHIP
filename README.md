# CodeAlpha UI/UX Internship Projects

This repository contains my UI/UX design projects completed as part of the CodeAlpha Internship Program.

## 📌 Projects

### Task 1 — Low-Fidelity Wireframes

Designed low-fidelity wireframes for a food delivery application.

**Focus areas:**

* User flow
* Screen structure
* Navigation
* Layout and information hierarchy

📁 Folder: `Task-1-Wireframes`

---

### Task 2 — High-Fidelity UI Design

Converted the wireframes into a high-fidelity food delivery application interface.

**Focus areas:**

* Color palette
* Typography
* Buttons and icons
* Cards and components
* Visual hierarchy
* UI/UX principles

📁 Folder: `Task-2-High-Fidelity-UI`

---

### Task 3 — UX Case Study

Conducted a UX case study of Zomato.

**Covered:**

* User journey analysis
* Strengths and weaknesses
* UX pain points
* Three proposed improvements
* Conceptual UI/UX mockups

📁 Folder: `Task-3-UX-Case-Study`

---

### Task 4 — Clickable Prototype

Created FoodNow, an interactive food delivery application prototype.

**Prototype flow:**

`Home → Restaurant → Item Details → Cart → Checkout → Live Tracking → Delivered`

**Features:**

* Restaurant search
* Category filtering
* Restaurant selection
* Item customization
* Quantity controls
* Coupon application
* Dynamic cart total
* Payment selection
* Order placement
* Live order tracking

📁 Folder: `Task-4-Prototype`
